# AI 3D Chase

A live browser-based 3D game with **AI-controlled hunters**, built with **Three.js**.

## Play now

**https://abhinavraj111.github.io/ai-3d-game/**

*(If the link shows a 404, enable GitHub Pages: Settings → Pages → Deploy from branch `main` / root)*

## How to play

- **Move**: WASD or Arrow keys (desktop) · Touch & drag on the lower half of the screen (mobile)
- You are the **blue orb**
- **Red AI hunters** chase you using pursuit AI
- Collect the **glowing yellow orbs** for points
- Survive as long as possible – more AI spawn over time
- Touch an AI hunter = Game Over

## Features

- Real-time 3D graphics with Three.js (WebGL)
- Simple but effective AI pursuit behavior
- Dynamic difficulty (more hunters appear as you collect)
- Score + survival timer + best score (saved locally)
- Responsive – works on desktop and mobile
- Shadows, fog, and glowing materials

Enjoy!
